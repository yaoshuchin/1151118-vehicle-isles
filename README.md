# 1151118 阿亮老師・無人載具 3D 建模實作 × 競技群島教學平台

本專案為 **曾慶良主任（阿亮老師）**「無人載具 3D 建模實作（無人機・人形格鬥機器人・水上無人船）」研習講義與競技群島 Web3D 互動教學系統之完整典藏版。

---

## 🚀 系統特色與架構

1. **三類載具・九大構型 3D 拆解**
   - **無人機（Drone）**：四軸競速、無人機足球（3v3 / 1v1）、空拍長續航機。
   - **人形格鬥機器人（Robot）**：關節、舵機、平衡機構與格鬥擂台競技。
   - **水上無人船（Boat / USV）**：滑行艇、雙體船、水翼船機構解說與水道繞標賽。

2. **完整教學與互動系統**
   - **課程首頁 (`portal.html`)**：章節導覽、示範 3D 成果、島嶼倒數與背景音樂切換。
   - **互動講義 (`course/`)**：章節投影片、機構拆解說明、六步生成器、FMEA 維修保養檢查表。
   - **機構拆解車庫 (`garage.html`)**：爆炸圖分解、X 光模式、零件功能詳解與推重比即時運算。
   - **載具博物館 (`museum.html`)**：歷史演進、經典型號與賽事發展。
   - **競技模擬場 (`arena.html`)**：無人機足球、格鬥擂台、水道繞標對戰模擬。
   - **AI 載具工坊 (`forge.html`)**：參數自訂、AI 輔助調參、匯出 GLB 3D 模型與 Blender Python 建模腳本。
   - **行動遙控器 (`controller.html`)**：手機掃 QR 碼連線遙控。
   - **排行榜 (`board.html`)**：成績紀錄與最佳挑戰。

3. **資安與研習門禁保護**
   - 原生瀏覽器 Web Crypto API（SHA-256 雜湊比對驗證），不儲存明文。
   - 驗證狀態寫入 `localStorage`，重新整理保持登入。
   - 介面右上角提供「🔒 重新上鎖」按鈕，方便隨時鎖定展示。

---

## 🛠️ 技術棧

- **前端核心**：原生 HTML5、CSS3、現代 JavaScript (ES Modules)
- **3D 引擎**：Three.js、OrbitControls、GLTFExporter
- **音訊與動態**：Web Audio API、HTML5 Video/Audio
- **部署架構**：GitHub Pages 靜態零伺服器託管
